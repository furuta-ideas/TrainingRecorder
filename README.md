# R-Bodyトレーニング記録

手描きUIに合わせたレスポンシブWebアプリ。教材は指定されたNotionの2026年10月9日復習ガイドから取り込んだ15種目、写真15点、動画11点です。既存のツアーFAQとは別のフォルダーに実装しています。

## 起動

このフォルダーで `node preview.mjs` を実行し、http://127.0.0.1:8781 を開きます。単純なファイルダブルクリックではなくHTTP/HTTPS経由で使用してください。iPhone・iPadはホストされたHTTPSのURLをSafariで開きます。

## 操作（2026-10-17）

- 黄色のメモ欄を1回クリック／タップして編集します。1行目はセット・回数・時間、2・3行目は秘訣。初期表示は登録済みメモで、変更内容は種目ごとに端末へ保存します。
- 最下段は前・次・累計時間・開始の1列です。上段のトレーニング名から選択・並べ替えを開きます。現在時刻、音声スイッチ、トレーニング終了は右上です。下段のボイスメモ、マイク、鉛筆、独立した10秒ボタンはありません。
- 上段のトレーニング名をクリック／タップして一覧を開きます。右端の6点ハンドルをつかんでドラッグし、順番を保存してください。タッチ・マウス両対応で、一覧の端では自動スクロールします。キーボードではハンドルをSpaceでつかみ、上下矢印で移動し、Enterで確定します。Escapeはその移動を取り消し、ダイアログのキャンセルは未保存の並べ替えを破棄します。新規種目は保存済み順序の末尾へ追加されます。
- 開始と同時に時間を計測します。音声は起動時OFF。ONではメモを読み上げ、読み終わったら残り秒数を案内します。重複した読み上げは溜めません。一時停止時間は累計に含みません。
- 時間指定がある場合はセット数を含む秒数を使用し、未指定は暫定60秒です。メモ編集画面の自動タイマーで種目ごとに変更できます。0秒は手動終了。設定時間に達するとログを保存して次の種目を自動開始し、最後の種目で停止します。
- 手動の種目移動・編集・リスト表示・終了・画面を離れる操作では、計測と音声を停止します。再読み込みでは停止状態で復元します。
- 終了で進行中の記録を保存してメール確認を表示します。送信受付後に表示される「終了」で閉じる処理を行います。通常のSafariタブやホーム画面アプリはOSが自動終了を拒否する場合があるため、完了画面と手動で閉じる案内を残します。
- メール実送信にはResend APIキーの本番登録が必要です。2026-10-17の診断時点では未登録でした。設定不足や送信失敗を送信成功として表示しません。設定診断APIは認証済みユーザーに設定の有無だけを返し、キーは返しません。
- 過去の記録・音声メモ・教材を保持します。端末間同期はありません。サイトデータを消すと端末内の記録も消えます。

## メニューの追加

画面のメニュー追加ボタンはありません。今後の教材追加は以下の共通メニューデータへ行います。

全端末に共通のメニューを増やす場合は、`dist/menus.json` の `menus` にレコードを追加し、`dist/media/` に教材を追加して再公開してください。既存の `id` は変更しないでください。ログとの対応を維持します。

```json
{
  "id": "変更しない一意なID",
  "name": "トレーニング名",
  "prescription": "2セット × 10回",
  "durationNote": "時間指定なし",
  "tips": "教材から確認したフォームのコツ",
  "images": [{"src":"media/example.png","notionRef":"Notionの安定ファイル参照"}],
  "video": {"src":"media/example.mp4","notionRef":"Notionの安定ファイル参照"},
  "needsConfirmation": false
}
```

動画なしは `video: null`。Notionの期限付き署名URLは保存せず、安定参照と取り込んだ教材ファイルを保持します。Notionのログイン情報・支払い情報などトレーニングに不要な内容は含めていません。Notionとの自動同期やNotionへの書き戻しはありません。

## トレーニング終了メール

右下「トレーニング終了」で計測と10秒カウントを停止し、進行中の記録を保存したうえで「メールでトレーニング結果を送信しますか？」と確認します。「送信して終了」「送信せず終了」「戻る」を選択できます。宛先は furuta.ideas@gmail.com、件名は「yyyymmdd 本日のトレーニング内容」。本文には各種目の日時・名称・メモ・実施時間と合計を記載します。

送信成功または送信せず終了を選ぶとアプリを閉じる処理を行います。Safariなどでブラウザが自動クローズを禁止している場合は、送信結果付きの終了完了画面を表示します。送信失敗・未設定時はダイアログに理由を表示し、再試行または送信せず終了を選べます。ログは削除しません。

iPhoneでも画面全体を端末の表示高に合わせ、ログのみペイン内でスクロールします。写真だけの4種目は、元の合成画像に含まれる2枚を表示上で分割し、領域の縦横比に応じて縦または横へ並べます。元画像はそのまま保持します。

送信先はサーバー側でも固定します。送信中の連打を禁止し、同じ内容は端末の送信済み情報とResendのIdempotency-Keyで重複を防ぎます。結果不明時は成功表示せず、ログを端末に保持します。Resendで受け付けられたことと、宛先メールボックスへの到着は別です。

### Resend設定（未設定では送信できません）

1. Resendに furuta.ideas@gmail.com で登録し、メール送信権限のAPIキーを発行します。既定の onboarding@resend.dev はResendアカウント本人宛てのテスト送信専用です。別のアカウントを利用する場合はドメインを認証し、そのドメインの送信元アドレスを指定してください。
2. ローカルで `./scripts/setup-mail.ps1` を実行し、APIキーを非表示入力します。生成する `.env.local` はGit管理対象外です。キーをチャットやGitHubへ貼り付けないでください。
3. Sitesのサーバー環境変数へ `RESEND_API_KEY` を秘密値として登録します。任意で `R_BODY_MAIL_FROM` に認証済み送信元を設定します。設定後は保存済みの版を再デプロイして反映します。

### サーバー構成

静的ページを同じURLのWorkerへ移行しています。ブラウザは同一オリジンへPOSTし、サーバーでログイン・Origin・データ形式を検証してResend APIを呼びます。送信サービスのキーをブラウザへ返しません。

`node scripts/build-worker.mjs` でHTML・JS・アイコンを埋め込んだ `dist/server/index.js` を生成し、`node scripts/validate-worker.mjs` で確認します。教材メディアはPublicリポジトリのコミット `6bc773f6ee3188bcf5c3ce7ba1963c9d8dbbc478` から固定パスだけを代理配信します。新しい教材ファイルを追加する際は、GitHubへ保存後にビルドスクリプト内の教材コミット参照も更新してください。

ローカルプレビューのメールAPIは未設定エラーを返します。実メールを送るテストは行いません。送信テストは `tests/mail.test.js` の疑似Resend応答で行います。

## iPhone・iPadのホーム画面アイコン

Safariでアプリ画面までログインし、共有メニューから「ホーム画面に追加」します。認証画面を追加しないでください。既存のホーム画面ショートカットに古いアイコンが残る場合は、ショートカットのみを削除して追加し直します。Safariのサイトデータは記録を含むため削除しないでください。

本人限定のSitesでは、アイコン画像にも認証が適用されます。iOSの画像取得でログイン情報が使われない場合に備え、apple-touch-iconとmanifest内のアイコンには、既にPublicのTrainingRecorderリポジトリ上にあるPNGを参照します。参照先はコミット固定です。アプリの公開範囲は変更しません。ルートの標準名apple-touch-icon.pngも配置します。

## 2026-10-15の指導メモと10秒カウント

Notionの10/15小川トレーナーのメモから、肋骨・腰の固定と背骨の分節運動を9種目へ反映しました。`menus.json` の `guidanceDate` / `guidanceSource` / `trainerNote` に出典と短いポイントを保持します。斜め腕立て伏せは当日の指導に合わせ1セット・10回目標、追加3回は無理なくと表示します。種目を特定できない細かい足の操作は転記していません。

右下の「音声ON・10秒開始」で、1秒後から1〜10を日本語で読み上げ、10秒で終了します。もう一度押すと途中停止できます。トレーニングの累計時間とは独立しています。メニュー編集・種目移動・終了・画面を離れる操作でカウントを停止します。音声には端末の読み上げ機能を使用し、非対応時は画面でカウントします。iPhoneでは音量を上げて使用してください。

## 2026-10-17 メニュー別メモ編集

上段の3行を編集ダイアログで変更できます。localStorageの既存記録と別の `menuNotes` に種目IDをキーとして保存し、種目移動や再読み込みでも維持します。端末間の自動同期はありません。過去の音声メモとログは削除しません。保存失敗時は編集画面を開いたままにし、既存の表示内容を保持します。

## 2026-10-18 オープニングと連続進行

起動・再読み込み時に、既存のキャラクターアイコン、R-bodyトレーニングアプリの文字、更新日時（日本時間）を3秒間表示します。表示中は操作を無効にし、裏でメニューと保存データを読み込みます。更新日時は配信するHTMLに固定し、新しい版を公開する際に更新します。

開始ボタンを1回押すと、保存されたメニュー順で自動的に次の種目へ進みます。自動切り替えでは教材の表示完了を待たずに次の計測を開始し、開始ボタンの実施中状態を維持します。最後の種目で停止します。手動操作による停止・一時停止・画面を離れた場合の停止は従来どおりです。

下段のメニューリストを削除し、上段の種目名を選択・並べ替えの入口にしました。上下ボタンと長押し操作を廃止し、48pxのドラッグハンドルからPointer Eventsで操作します。並べ替え後も現在種目のIDを維持し、保存順は再読み込みと自動進行に反映します。
